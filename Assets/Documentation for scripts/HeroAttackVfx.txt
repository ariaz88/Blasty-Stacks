================================================================================

PURPOSE
-------
Plays a one-shot attack VFX prefab on every swing of a hero, and hides the
hero's built-in slash sprite that the new effect replaces. One component per
hero prefab, on the ROOT (next to PlayerManager). Each hero gets its own effect
by assigning a different vfxPrefab.

FIELDS
------
  vfxPrefab         one-shot VFX prefab whose ROOT has a ParticleSystem (VFXKit
                    prefabs: root has no emission, Play(true) plays every layer).
                    Empty = component does nothing.
  offset            LOCAL position of the effect's origin under the hero, for a
                    hero facing right. For an arc effect = centre of the swing.
                    Valkyrie: (0.139, 0.264) = centre of the circle her sword
                    tip travels in the Slashing clip (radius 0.684).
  scale             uniform local scale of the effect. Valkyrie: 1.
  sortingLayerName  / sortingOrder  applied to every ParticleSystemRenderer of
                    the effect. Default Default/20 - hero sprites draw at order 1.
  replacedRenderers the hero's built-in slash sprites (Valkyrie: SlashFX). Their
                    SPRITE is set to null in Awake.
  poolSize          max pooled instances (default 3).

  runtime: _pool (List<ParticleSystem>), _next (round-robin index)

FLOW
----
  Awake()  clears the sprite of every replacedRenderers entry.
  Play()   [public, called by PlayerAnimatitorManager.EnableDamageCollier]
      Rent() an instance, set localPosition = offset, localRotation = identity,
      localScale = scale, Clear + Play(true).
  Rent()   an idle (not IsAlive) pooled instance; else create one while under
           poolSize; else recycle round-robin.
  Create() Instantiate as a CHILD of the hero; on every child system set
           playOnAwake=false, simulationSpace=Local, scalingMode=Hierarchy;
           apply the sorting to every renderer; stop+clear.

HOW IT CONNECTS
---------------
  - Triggered by the attack clip's EnableDamageCollier animation event through
    PlayerAnimatitorManager (GetComponentInParent). No change to damage/timing.
  - The effect is a child of the hero, so it moves with the hero, and the
    hero's negative X scale (PlayerManager.FaceLeft) mirrors it - Hierarchy
    scaling is what lets that sign reach every layer.
  - VFX prefabs are generated by VFXKit into Assets/VFXKit/Effects/<name>/.
    The prefab is REBUILT on import - never hand-edit it; edit the effect's
    .vfx.json, or tune position/size/sorting on this component.

NOTES
-----
  - Why sprite=null and not enabled=false: the heroes are Spriter rigs, and
    Spriter2UnityDX's EntityRenderer.OnEnable re-enables EVERY renderer of the
    rig. The attack clip animates SlashFX colour/transform but never its sprite,
    so a null sprite stays hidden. (enabled=false was tried and did not stick.)
  - Sorting is forced at spawn, not in the VFX prefab, because VFXKit rebuilds
    the prefab and would wipe hand-set sorting.
  - Gate swings also fire EnableDamageCollier, so the effect plays on gate
    attacks too (intended).
  - Tested 2026-09-25 in Level_1_Stage_1, 1 Valkyrie vs 1 Reaper.
  - Heroes wired (all 4 Deployed, 2026-09-25). Offset = centre of that hero's
    weapon-tip circle in its attack clip:
      Player_Valkyrie        -> valkyrie_slash (0.139, 0.264)  replaces SlashFX
      Player_Dark_Oracle_01  -> oracle_slash   (0.139, 0.285)  replaces SlashFX
      Player_CowMinotaur_02  -> cow_slash      (0.139, 0.285)  replaces SlashFX
      Player_Minotaur_02     -> mino_slash     (0.159, 0.392)  no SlashFX on this rig
  - ENEMIES use it too (despite the name): EnemyAnimatorManager.EnableEnemyDamageCollier
    calls Play(). Enemy roots start mirrored (scale.x = -1); the effect is a child,
    so it mirrors with them. Wired 2026-09-25 - the three enemy types of stages 1-10:
      Enemy_Reaper_Man_01       -> ember_arc_ghost (0.139, 0.285)
      Enemy_Zombie_villager     -> candy_slash     (0.139, 0.285)
      Enemy_Skeleton_Crusader_1 -> ember_arc       (0.139, 0.264)  (stage-6 Swordsman
                                   reuses this prefab)
