  Layer: Core / SaveLoad
================================================================================

PURPOSE
-------
The complete shape of the player's save file. One instance of this object is
serialized to JSON by JsonUtility and stored in a single PlayerPrefs key.
Everything the game remembers between sessions lives here.

FIELDS
------
  version              (int, =1)  schema version, used by SaveSystem migration.

  Economy
    gems               (int) premium currency - used for upgrades and revives
    coins              (int) soft currency
    heroXp             (int) hero experience

  Units
    units              (List<UnitStateEntry>) per-unit unlock / level / deployed
    deployedUnitOrder   (List<int>) unitIds in the player's chosen display order
    undeployedUnitOrder (List<int>) same for the bench
        These two exist so the roster screen remembers how the player arranged
        their cards, which is presentation state rather than pure progression.

  Stages
    stages             (StageSection) legacy single-chapter progress
    levels             (List<LevelProgress>) per-level progress, the current path

  Battle allowance
    battleEnergy       (BattleEnergyState) the BATTLE button's rolling 24h cap
                       and its (placeholder) energy balance. Global, not
                       per-scene - see BattleEnergyService.

  Tutorials
    completedTutorials (List<string>) TutorialSequenceSO.TutorialId of every
                       tutorial the player has been shown. Added 2026-08-25 with
                       NO version bump: saves written before it simply have no
                       such key, and JsonUtility leaves the field initializer in
                       place. Written only through SaveSystem.SetTutorialCompleted
                       / ResetTutorials - see TutorialManager.

  savedAtUtc           (string) timestamp of last save

NESTED TYPES
------------
  UnitStateEntry { unitId, unlocked, level, isDeployed }
      The constructor clamps level to a minimum of 1, so a corrupt 0 can never
      enter the model.

  LevelProgress  { levelId, highestUnlocked (0-based), stars[] }
      stars array length equals the number of stages in that level.

  StageSection   { highestUnlocked (0-based), stars[] }
      An earlier, single-chapter representation kept alongside 'levels'.

  BattleEnergyState { windowStartUtc, battlesUsed, energy }
      windowStartUtc is a round-trip ("o") UTC string marking when the current
      24h battle window opened; empty means no window is open and the next
      battle opens one. battlesUsed counts battles started inside that window
      and MAY exceed the daily limit once the player pays with energy. energy
      is a PLACEHOLDER balance - no economy grants it yet.

HOW IT CONNECTS
---------------
  - SaveSystem owns exactly one cached instance and serializes it.
  - GameStartManager converts UnitStateEntry into PlayerUnitsModel.UnitState.
  - HomeManager / StageCard read levels[] for stars and unlock state.
  - BattleEnergyService is the only writer of battleEnergy (through
    SaveSystem.SetBattleEnergy).

NOTES
-----
  - Two overlapping stage representations ('stages' and 'levels') coexist. New
    code should use 'levels'; 'stages' is the older single-chapter form.
  - JsonUtility does not serialize properties or dictionaries, which is why
    everything here is a public field or a List.
