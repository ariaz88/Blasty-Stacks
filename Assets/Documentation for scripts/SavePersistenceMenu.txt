  Layer: Editor
  Scenes: none
================================================================================

PURPOSE
-------
One-click wipe of all saved progress, so the next Play boots as a brand-new
player: stage 1, starting currency, and the first-run tutorial.

HISTORY (2026-09-22): this file used to ALSO hold a checkable "Save & Load
Enabled" item that flipped the SavePersistence debug gate. Saving is now
unconditional - SavePersistence, its on-screen SavePersistenceDebugPanel and the
toggle item are all DELETED. Only the opposite operation, erasing what was
written, is still needed for testing, and that is what remains here.

MENU ITEMS
----------
  Tools/Save System/Wipe Saved Progress Now     (priority 0)
      WipeSavedProgress()
          Shows an EditorUtility.DisplayDialog confirmation first (the action
          is irreversible), then calls WipeNow().

METHODS
-------
  WipeNow()  [public static]
      The wipe with NO dialog, for scripted / automated runs. Delegates to
      SaveSystem.WipeAllProgress(), which deletes:
        1. "GAME_SAVE_V1"    - units, currency, stars/unlocks, completed
                               tutorials, deploy stages, battle energy
        2. "LM.CurrentStage" - the global stage (LevelManager's own key)
      and drops SaveSystem's in-memory cache, so a later Save() in the same
      editor session cannot resurrect the old blob from the still-loaded cache.
      Logs a confirmation line.

HOW IT CONNECTS
---------------
  - SaveSystem     - WipeAllProgress() is the single shared implementation.
  - LevelManager   - owns "LM.CurrentStage"; WipeAllProgress references
                     LevelManager.PlayerPrefsKey by name rather than a literal.
  - GameStartManager - its EDITOR-ONLY "Reset Progress On Play" tickbox (on the
                     GameStartManager object in StarterScene) calls the same
                     SaveSystem.WipeAllProgress(), so the menu and the checkbox
                     can never wipe differently. Use the checkbox for "every
                     Play run starts fresh"; use this menu item for a one-off.

NOTES
-----
  - Deleting a save cannot be undone from the editor. Before wiping real test
    progress, copy PlayerPrefs "GAME_SAVE_V1" out first - on Windows it lives in
    the registry under HKCU\Software\DefaultCompany\Stacky Warriors.
  - Key names now come from SaveSystem / LevelManager constants, not literals.
    They are still hard-coded in the Editor verification harnesses
    (CPCombatVerification, EarlyCampaignVerification,
    EarlyCampaignEconomyVerification) - grep there if a key is ever renamed.
