PURPOSE
-------
Holds the weighting curves that USED to convert a unit's raw stats into a single
"Combat Power" (CP) number via a weighted sum. That formula was replaced because
it ranked the shipped roster incorrectly - see CPCalculator.txt NOTES.

FIELDS
------
  Stat weights - x = level, y = how much that stat counts toward CP
    wAttackByLevel        (default 1.00 -> 0.90)   attack dominates CP
    wHPByLevel            (default 0.15 -> 0.12)
    wMoveSpeedByLevel     (default 0.25 -> 0.20)
    wAttackSpeedByLevel   (default 0.40 -> 0.45)   grows in importance
    wDefenseByLevel       (default 0.00 -> 0.05)   ignored at low level

    The range weight has been removed (A2). Existing .asset files may still carry
    a serialized `wRangeByLevel` block until Unity next re-saves them.

  Type flavour
    meleeMultByLevel      (default flat 1.00)
    rangedMultByLevel     (default flat 1.05)  ranged units score ~5% higher

  Safety
    wClamp                (Vector2, default -10..10) clamps each evaluated weight
    globalWeightScaleByLevel  (default flat 1.00) scales ALL weights at once

HOW IT CONNECTS
---------------
  - Consumed by CPWeightMath.Evaluate(). NOTHING calls CPWeightMath any more -
    CPCalculator dropped it in the A1 rewrite. This is currently a dead branch.
  - Assets: "Assets/Scriptable Objects/CP/Player CP.asset" and "EnemyCP.asset".
  - Both assets author meleeMultByLevel / rangedMultByLevel entirely off the
    level axis (keys at t ~= -389 and t ~= -730), so every typeMult evaluated to
    1.0 anyway. The new formula has no typeMult at all.
