PURPOSE
-------
Renders ONE card on the level-up screen and reports the click back.

A card is a (hero, stat) pair. The portrait says WHO gets the buff, the value says
how much, and the star row PREVIEWS what that hero's stack will look like once the
card is taken - so the player can see what the pick buys before taking it.

INSPECTOR FIELDS
----------------
  firstUI         (GameObject)  shown only on a hero's FIRST star of this buff,
                  alongside the NEW ribbon
  iconImage       (Image)       the buff icon; swaps to evolvedIcon when maxed
  portraitImage   (Image)       NEW. the hero this card buffs. Optional - hidden
                  automatically on a global card, or when the manager has no
                  UnitsDatabaseSO assigned
  nameText        (TextMeshProUGUI)
  descriptionText (TextMeshProUGUI)
  valueText       (TextMeshProUGUI)  NEW. the big green "+50%". OPTIONAL - if the
                  prefab has no such label the value is appended to the
                  description instead, so the number is never invisible
  starsContainer  (Transform)
  starImages      (Image[])
  newRibbon       (GameObject)

RUNTIME STATE
-------------
  offer      (BuffOffer)  the card currently displayed
  onSelected (Action<BuffOffer>)  the manager's callback

FLOW
----
  Awake                 wires the Button's onClick to OnClick().

  Init(BuffOffer data, Sprite portrait, Action<BuffOffer> callback)
        resultingStars = data.currentStars + 1
        isMaxed        = resultingStars >= skill.MaxStars

        portrait   assigned if non-null, otherwise portraitImage is hidden
        icon       evolvedIcon when isMaxed, else normalIcon
        value      "+{increment*100}%"  (increments are stored as fractions)

        First star      -> firstUI ON, NEW ribbon ON, star row HIDDEN
        Middle stars    -> star row shown with `resultingStars` stars lit
        Maxed           -> firstUI OFF, ribbon OFF, star row HIDDEN (the evolved
                           art carries the message instead)

  OnClick()  invokes the callback with this card's BuffOffer. Public, so it can
             also be wired from the prefab's OnClick list - but do NOT do both,
             Awake already adds the listener.

HOW IT CONNECTS
---------------
  RogueliteManager.OpenSkillSelection() -> Init(offer, portrait, OnOfferChosen)
  BuffOffer / BuffDraw                  -> the data being rendered
  UnitDefinitionSO.portrait             -> where the hero portrait comes from,
                                           looked up by the manager on classType

NOTES
-----
  - SIGNATURE CHANGED. The old Init(SkillData, int timesSelected, Action<SkillData>)
    is gone; a card now carries a whole BuffOffer because it needs to know which
    hero it targets.
  - The old >= 5 / > 5 mismatch between this script and the manager's icon-row
    code is fixed: both now compare against SkillData.MaxStars.
  - portraitImage and valueText are new and will be NULL on prefabs authored
    before this change. Both are null-guarded, so old prefabs still work - they
    just show no portrait and fold the value into the description.
